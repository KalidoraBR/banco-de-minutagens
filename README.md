# Banco de Minutagens

App Android para guardar as minutagens de episódios de séries: **abertura**, **recap** e **encerramento**.

- Dados das séries e episódios vêm do [TMDB](https://www.themoviedb.org/).
- Sincronização opcional com uma planilha do Google Sheets.
- Envio opcional das minutagens para o [IntroDB](https://introdb.app).
- Quatro visuais (Temas A, B, C e D), estatísticas, backup automático e aviso de estreias.

## Instalar

Baixe o arquivo `.apk` mais recente em **Releases** e abra no celular Android.
O próprio app avisa quando sair uma versão nova.
